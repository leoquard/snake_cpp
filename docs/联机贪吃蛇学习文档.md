`terminal.cpp` 需要的头文件：

- `#include <cstddef>`：`std::size_t`

`client_main.cpp`：`#include <ui/terminal.hpp>`、`#include <csignal>`。

### 4.2 接口（直接誊入头文件）

```cpp
#pragma once
#include <optional>
#include <string_view>
#include <termios.h>

namespace snake {

class Terminal {
public:
    Terminal();                    // 进原始模式 + 备用屏 + 隐藏光标
    ~Terminal();                   // 恢复终端（RAII，绝不能忘）

    Terminal(const Terminal&) = delete;
    Terminal& operator=(const Terminal&) = delete;

    void clear();                          // 清屏
    void move_to(int row, int col);        // 0 基坐标 → ANSI 的 1 基
    void put(std::string_view text);       // 在当前位置输出
    std::optional<char> read_char();       // 阻塞读一个字节

private:
    termios saved_{};
    bool raw_active_ = false;
};

}  // namespace
```

### 4.3 工具函数 `write_all`

放匿名命名空间，签名 `void write_all(std::string_view text)`。循环处理四种情况：

1. `write` 返回 > 0：`text.remove_prefix(n)` 切掉已写部分，继续
2. 返回 -1 且 `errno == EINTR`：被信号打断，继续重试
3. 返回 -1 其他错误：无法恢复，直接 return
4. 循环条件：`text` 非空就一直写

必须循环的原因：`write` 不保证一次写完（短写），也会被信号打断。这个模式在 socket 代码里会原样复用。

### 4.4 构造函数：四步

1. **保存现状**：`tcgetattr(STDIN_FILENO, &saved_)`，失败（非终端）直接 return，`raw_active_` 保持 false
2. **改标志**：
   - 局部变量 `termios raw = saved_;`（在副本上改，**绝不改 `saved_`**）
   - `raw.c_lflag &= ~(ICANON | ECHO);`
     - `ICANON`：关行缓冲，按键不等回车
     - `ECHO`：关回显
     - 保留 `ISIG`：Ctrl+C 才能产生 SIGINT
   - `raw.c_cc[VMIN] = 1; raw.c_cc[VTIME] = 0;`：阻塞到至少 1 字节
   - `tcsetattr(STDIN_FILENO, TCSAFLUSH, &raw);`，失败 return
   - 成功置 `raw_active_ = true;`
3. **接管屏幕**（一次 write_all）：`\033[?1049h` 进备用屏、`\033[?25l` 隐藏光标、`\033[2J\033[H` 清屏归位
4. **自检**：构造失败的路径上，析构不能乱发恢复序列——靠 `raw_active_` 区分

### 4.5 析构函数

- 第一行 `if (!raw_active_) return;`
- 依次写：`\033[?25h` 显示光标、`\033[?1049l` 退出备用屏
- 最后 `tcsetattr(STDIN_FILENO, TCSAFLUSH, &saved_)`
- 顺序：先还屏幕，再还终端模式，反了会闪
- `TCSAFLUSH` 会丢弃运行期间堆积的输入，避免退出后字符打到 shell

### 4.6 `clear` / `move_to` / `put`

- `clear()`：`write_all("\033[2J\033[H")`
- `move_to(row, col)`：
  1. `char buf[32];`
  2. `std::snprintf(buf, sizeof buf, "\033[%d;%dH", row + 1, col + 1);`
  3. 检查返回值 `n > 0 && n < (int)sizeof buf`
  4. `write_all(std::string_view(buf, (std::size_t)n))`
  - **ANSI 行列从 1 开始，必须 +1**
  - 不能用 `std::string(buf)`：只知道长度，不保证有 `\0`（其实有，但按长度构造更严谨）
- `put(text)`：一行 `write_all(text)`

### 4.7 `read_char`

- `char c = 0; ssize_t n = ::read(STDIN_FILENO, &c, 1);`
- 三种返回值：
  - `n == 1`：返回 `c`
  - `n == 0`：EOF
  - `n == -1`：错误，含被信号打断的 `EINTR`
- M1 统一：后两种返回 `std::nullopt`，让上层决定退出
- 不要写重试循环——重试了信号就永远退不出去；M2 用 `poll` 重新设计

### 4.8 信号处理（最容易踩的坑）

- 全局标志：`volatile std::sig_atomic_t g_running = 1;`
- 处理函数只做赋值：`void on_signal(int) { g_running = 0; }`
- 安装处理器四步（`install_signal_handlers()`，main 开头调用）：
  1. `struct sigaction sa {};`
  2. `sa.sa_handler = on_signal;`
  3. `sigemptyset(&sa.sa_mask); sa.sa_flags = 0;`
  4. `::sigaction(SIGINT, &sa, nullptr);`，SIGTERM 同样再来一次
- **`sa_flags = 0` 是关键**：glibc 的 `signal()` 默认带 `SA_RESTART`，会把阻塞的 `read()` 自动重启，信号来了主循环醒不过来。不设它，`read()` 返回 `EINTR` → `nullopt` → 循环退出 → 析构恢复终端

### 4.9 main 主流程

1. `install_signal_handlers();`
2. `snake::Terminal term;`（析构自动恢复，别手动清理）
3. `term.clear();`
4. 画边框（`kBoardCols = 40`、`kBoardRows = 16`）：
   - 横边：`col` 从 0 到 `kBoardCols + 1`，在第 0 行和第 `kBoardRows + 1` 行画；首尾画 `+`，其余 `-`
   - 竖边：`row` 从 **1** 到 `kBoardRows`（跳过角），在第 0 列和第 `kBoardCols + 1` 列画 `|`
   - 每个字符先 `move_to`
5. `move_to(kBoardRows + 3, 2)` + `put("... - press q to quit")`
6. 事件循环：`while (g_running) { auto ch = term.read_char(); if (!ch) break; if (*ch == 'q') break; }`
7. `return 0;`

### 4.11 常见坑清单

1. `move_to` 忘 `+1`：整体偏一格
2. 竖边循环从 row=0 开始：把角上的 `+` 盖成 `|`
3. 直接在 `saved_` 上改标志：恢复的不是原始终端
4. 构造失败也执行析构恢复：没用备用屏却退备用屏
5. `write` 不循环：偶发输出截断
6. 用 `signal()` 而非 `sigaction`：`SA_RESTART` 导致 Ctrl+C 退不出
7. `cout/printf` 和 `write` 混用：输出乱序，统一下来
8. `TCSAFLUSH` 吞掉进入原始模式前敲的键：测试时等程序起来再按
9. 不设 `VMIN/VTIME`：行为依赖系统默认
10. 忘记 `raw_active_` 的意义：它区分“我接管了终端”和“我只是普通程序”

## 五、速查表

### termios 关键标志

| 标志 | 含义 | 我们的处理 |
|---|---|---|
| `ICANON` | 行缓冲（等回车） | 关闭 |
| `ECHO` | 输入回显 | 关闭 |
| `ISIG` | Ctrl+C/Z 产生信号 | 保留 |
| `VMIN` | read 最少读多少字节 | 1 |
| `VTIME` | read 超时（0.1 秒单位） | 0 |

### ANSI 转义序列

| 序列 | 含义 |
|---|---|
| `\033[2J` | 清屏 |
| `\033[H` | 光标回左上角 |
| `\033[<行>;<列>H` | 光标定位（1 基） |
| `\033[?1049h` / `\033[?1049l` | 进 / 出备用屏 |
| `\033[?25l` / `\033[?25h` | 隐藏 / 显示光标 |
